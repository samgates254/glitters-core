# API v1

Base path: `/api/v1/`

The contract is the OpenAPI schema at `/api/v1/schema/`. Swagger UI is at `/api/v1/docs/`. In development both are public. With `DEBUG` off, both require a staff session that has confirmed MFA.

## Organization endpoints

Collections are paginated (`count`, `next`, `previous`, `results`), 25 per page, `page_size` up to 100. An organization permission below means the caller has an active account, an active membership, and an active organization, and the role grants that permission.

| Method | Path | Auth | Purpose |
|---|---|---|---|
| `POST` | `/api/v1/organizations/` | Verified email | Create an active organization. The caller becomes the owner. |
| `GET` | `/api/v1/organizations/` | Authenticated | Organizations the caller can operate. |
| `GET` | `/api/v1/organizations/{organization_id}/` | `organization.view` | Organization profile. |
| `PATCH` | `/api/v1/organizations/{organization_id}/` | `organization.update` and, for legal name, type, reference, slug, and country, `organization.manage_settings` | Update submitted fields. |
| `POST` | `/api/v1/organizations/{organization_id}/status/` | Owner deactivation, or staff | Returns `{id, status}` only. |
| `GET` | `/api/v1/me/memberships/` | Authenticated | The caller's memberships, including non-active organizations. |
| `GET` | `/api/v1/organizations/{organization_id}/members/` | `organization.view` | Members who are not removed. |
| `GET` | `/api/v1/organizations/{organization_id}/members/{membership_id}/` | `organization.view` | One membership in that organization. |
| `PATCH` | `/api/v1/organizations/{organization_id}/members/{membership_id}/` | `organization.manage_roles` | Change a lower role. Not `owner` and not yourself. |
| `POST` | `/api/v1/organizations/{organization_id}/members/{membership_id}/suspend/` | `organization.manage_members` | Suspend an active lower member. |
| `POST` | `/api/v1/organizations/{organization_id}/members/{membership_id}/reactivate/` | `organization.manage_members` | Restore a suspended lower member. |
| `POST` | `/api/v1/organizations/{organization_id}/members/{membership_id}/remove/` | Self-leave, or `organization.remove_members` | Remove a non-owner. |
| `POST` | `/api/v1/organizations/{organization_id}/ownership-transfer/` | `organization.transfer_ownership` | The acting owner becomes admin. The target becomes owner. |
| `GET`, `POST` | `/api/v1/organizations/{organization_id}/invitations/` | `organization.invite_members` | List pending invitations or create one. The raw token is emailed, not returned. |
| `GET` | `/api/v1/organizations/{organization_id}/invitations/{invitation_id}/` | `organization.invite_members` | Invitation state without the token. |
| `POST` | `/api/v1/organizations/{organization_id}/invitations/{invitation_id}/resend/` | `organization.invite_members` | Rotates the token. |
| `POST` | `/api/v1/organizations/{organization_id}/invitations/{invitation_id}/revoke/` | `organization.invite_members` | Revokes a pending invitation. |
| `POST` | `/api/v1/invitations/accept/` | Authenticated | Body `{token}`. Verified email must match. |
| `POST` | `/api/v1/invitations/inspect/` | Authenticated | Body `{token}`. Does not accept and does not return the invited email. |
| `GET` | `/api/v1/organizations/{organization_id}/permissions/` | `organization.view` | The caller's role and granted permissions in that organization. |
| `GET` | `/api/v1/organization-roles/` | Authenticated | Role catalogue and reserved future permissions. |
| `GET` | `/api/v1/organizations/{organization_id}/audit/` | `organization.view_audit` | Append-only organization events. |

## Location endpoints

Reference reads require an active authenticated account. Resolve validates an address and does not insert a row. Responses do not include coordinates.

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/api/v1/locations/countries/` | Active countries. |
| `GET` | `/api/v1/locations/countries/{country}/areas/` | Areas in that country. Omit `parent_id` for roots. Optional `level_code`. |
| `GET` | `/api/v1/locations/areas/{area_id}/` | The area, its ancestors, its children, and the country's level ladder. |
| `GET` | `/api/v1/locations/localities/` | `q` of at least two characters. Optional `country` and `administrative_area_id`. |
| `GET` | `/api/v1/locations/search/` | Areas and localities matching `q`. Optional `country`. |
| `POST` | `/api/v1/locations/addresses/resolve/` | Validate a country, area, locality, and street. CSRF applies. |

Resolve example:

```json
{
  "country": "KE",
  "administrative_area_id": "2b0b6b0e-1c3a-4d2e-9f10-6a1c0b9d4e11",
  "street_line": "Mpaka Road",
  "postal_code": "00606"
}
```

The response includes `administrative_path` and does not include latitude or longitude.

## Property endpoints

Pagination matches organizations. A property the caller cannot see is 404. A suspended organization or a non-active membership is 403. List and search bodies have no `coordinates` field. Detail includes `coordinates` only when the caller can update that property.

| Method | Path | Who |
|---|---|---|
| `POST` | `/api/v1/properties/` | Personal: any active user. Organization: `property.create`. |
| `GET` | `/api/v1/properties/` | Properties the caller can access. |
| `GET` | `/api/v1/properties/{property_id}/` | A caller who can access that property. |
| `PATCH` | `/api/v1/properties/{property_id}/` | `property.update` or a `manage` grant. Cannot archive. |
| `POST` | `/api/v1/properties/{property_id}/archive/` | `property.archive` or a `manage` grant. |
| `GET`, `PUT` | `/api/v1/properties/{property_id}/characteristics/` | Read with access. Replace with update rights. Body `{characteristics: [{code, value}]}`. |
| `GET`, `POST` | `/api/v1/properties/{property_id}/relationships/` | Read with access. Add with update rights. |
| `PATCH` | `/api/v1/properties/{property_id}/relationships/{party_id}/` | Update rights. Cannot set `verified`. |
| `POST` | `/api/v1/properties/{property_id}/relationships/{party_id}/revoke/` | Update rights. Optional `revoke_access`. |
| `POST` | `/api/v1/properties/{property_id}/access/{access_id}/revoke/` | Update rights. The last personal manager cannot be removed. |
| `GET` | `/api/v1/properties/{property_id}/audit/` | Update rights. Append-only property events. |

List filters: `status`, `property_type`, `management_context`, `organization_id`, `parent_id`, `country`, `administrative_area_id`, `near` with `radius_m`, and `bbox` as `min_lon,min_lat,max_lon,max_lat`. `near` is `latitude,longitude`. Nearby results add `distance_m` in 100 metre bands. An organization filter outside the caller's access returns an empty page.

Personal create example:

```json
{
  "management_context": "personal",
  "property_type": "residential",
  "property_subtype": "apartment",
  "name": "Kilimani Apartment",
  "hierarchy_role": "standalone"
}
```

A 201 body includes `reference` beginning with `GLT-`, `status` `draft`, and no `coordinates` key until a point exists and the caller may see it. Setting `status` to `active` requires an address:

```json
{
  "status": "active",
  "address": {
    "country": "KE",
    "administrative_area_id": "2b0b6b0e-1c3a-4d2e-9f10-6a1c0b9d4e11",
    "street_line": "Mpaka Road"
  },
  "coordinates": {"latitude": -1.2921, "longitude": 36.8219},
  "characteristics": [
    {"code": "bedrooms", "value": 3},
    {"code": "floor_area_sqm", "value": "85.50"}
  ]
}
```

A claimed owner is not verified:

```json
{
  "subject_kind": "person",
  "user_id": "6f0c1a2b-3d4e-5f60-8172-93a4b5c6d7e8",
  "role": "owner"
}
```

The response has `status` `claimed` and `legal_title_verified` false. Adding `access_capability` is a separate choice from the role. An organization subject rejects `access_capability`. An access row includes `origin` (`direct` or `inherited`) and `inherited_from`.

## Marketplace endpoints

Pagination matches organizations. Public collection and detail allow anonymous reads and return only eligible published listings. A missing or ineligible public listing is 404. Publisher and moderation writes use the session CSRF check. Errors stay `{errors, request_id}`.

Public fields are `reference`, `listing_type`, `title`, `description`, `highlights`, `description_origin`, `published_at`, `expires_at`, `property` (type, subtype, bedrooms, bathrooms, floor area, land area), `location` (country, administrative area, locality), `price`, `advertiser` (display name and organization name), and `media`. Media `asset_reference` is `/api/v1/marketplace/listings/{reference}/media/{link_id}/`. They do not include coordinates, street address, parties, mandate evidence, moderation notes, the property id, the object key, or the `GLT-` reference.

| Method | Path | Who |
|---|---|---|
| `GET` | `/api/v1/marketplace/listings/` | Public. Eligible published listings. |
| `GET` | `/api/v1/marketplace/listings/{reference}/` | Public. One eligible listing. |
| `POST` | `/api/v1/marketplace/listings/{reference}/enquiries/` | Public. Creates an enquiry on an eligible listing. The response is `{id, status}`. |
| `GET` | `/api/v1/marketplace/enquiries/` | Authenticated inbox. Personal rows for the caller, and organization rows where the caller has `leads.view` or `leads.manage`. |
| `GET` | `/api/v1/marketplace/enquiries/{id}/` | The same reader. Strangers receive 404. A member of that organization without a lead permission receives 403. |
| `PATCH` | `/api/v1/marketplace/enquiries/{id}/assignment/` | Personal advertiser or member with `leads.manage`. Assigns, reassigns, or clears assignee (`{"user_id": "<uuid> | null"}`). |
| `POST` | `/api/v1/marketplace/enquiries/{id}/transitions/` | Personal advertiser or member with `leads.manage`. Moves enquiry on the lifecycle graph (`{"status": "<status>", "reason_code": "..."}`). |
| `GET`, `POST` | `/api/v1/marketplace/publisher/listings/` | Advertiser. Create returns 201 and a draft. |
| `GET`, `PATCH` | `/api/v1/marketplace/publisher/listings/{listing_id}/` | The personal advertiser, or an organization publisher. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/submit/` | Advertiser. Moves a draft to pending review. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/revise/` | Advertiser. Rejected returns to draft. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/pause/` | Advertiser. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/resume/` | Advertiser. Refused while a moderation hold is set. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/withdraw/` | Advertiser. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/complete/` | Advertiser. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/renew/` | Advertiser. 201 and a new draft. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/expire/` | Advertiser, when the term has elapsed. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/accept-description/` | Advertiser. Accepts an assisted draft description. |
| `POST` | `/api/v1/marketplace/publisher/listings/{listing_id}/media/` | Advertiser. Attaches a stored photograph while the listing is a draft. |
| `DELETE` | `/api/v1/marketplace/publisher/listings/{listing_id}/media/{link_id}/` | Advertiser. Detaches that link. |
| `GET`, `POST` | `/api/v1/marketplace/mandates/` | A caller who can see or grant a mandate. |
| `GET` | `/api/v1/marketplace/mandates/{mandate_id}/` | A participant. |
| `POST` | `/api/v1/marketplace/mandates/{mandate_id}/accept/` | The representative. |
| `POST` | `/api/v1/marketplace/mandates/{mandate_id}/reject/` | The representative. |
| `POST` | `/api/v1/marketplace/mandates/{mandate_id}/revoke/` | A grantor, principal, representative, or current updater. |
| `GET` | `/api/v1/marketplace/listings/{reference}/media/{link_id}/` | Public. One verified listing photograph on an eligible published listing. Returns a short-lived `{url, expires_in}`. |
| `GET` | `/api/v1/marketplace/properties/{property_id}/media/` | Property update rights, or an in-force mandate for photographs. |
| `POST` | `/api/v1/marketplace/properties/{property_id}/media/upload-sessions/` | The same authority. Body `{kind, mime_type, size_bytes}` and optional caption and alt text. Returns a presigned PUT. A client storage URL or `upload_status` is rejected. |
| `POST` | `/api/v1/marketplace/media/upload-sessions/{session_id}/complete/` | The session creator, still authorized. Verifies the object and returns the media row. |
| `POST` | `/api/v1/marketplace/media/upload-sessions/{session_id}/cancel/` | The session creator, while the session is `created`. |
| `POST` | `/api/v1/marketplace/properties/{property_id}/media/{media_id}/download/` | Photographs: update rights or an in-force mandate. Documents: update rights. Returns a short-lived `{url, expires_in}`. |
| `POST` | `/api/v1/marketplace/properties/{property_id}/media/{media_id}/remove/` | The same media authority. Rejects the row, detaches listing links, and deletes the object. |
| `GET` | `/api/v1/marketplace/moderation/listings/{listing_id}/` | Staff with confirmed MFA. |
| `POST` | `/api/v1/marketplace/moderation/listings/{listing_id}/approve/` | Staff with confirmed MFA. |
| `POST` | `/api/v1/marketplace/moderation/listings/{listing_id}/reject/` | Staff with confirmed MFA. Body `{reason}`. |
| `POST` | `/api/v1/marketplace/moderation/listings/{listing_id}/suspend/` | Staff with confirmed MFA. |
| `POST` | `/api/v1/marketplace/moderation/listings/{listing_id}/reinstate/` | Staff with confirmed MFA. |
| `POST` | `/api/v1/marketplace/moderation/listings/expire-due/` | Staff with confirmed MFA. Expires up to 500 overdue rows. |

Public filters: `listing_type`, `property_type`, `country`, `administrative_area_id`, `locality_id`, `price_min`, `price_max`, `currency`, `bedrooms`, `bathrooms`, `floor_area_min`, `land_area_min`, `published_after`, `published_before`, `q`, and `sort`. Sort values are `published_at`, `-published_at`, `price`, and `-price`. The default is `-published_at`. `near`, `bbox`, `lat`, `lon`, `latitude`, `longitude`, `radius_m`, `distance`, and `radius` are rejected.

The enquiry inbox is read-only. It orders by `created_at` descending, then `id` descending. Filters are `status`, `listing_reference`, `created_after`, and `created_before`. A date without a time is the start of that local day. `organization_id`, `advertiser_id`, `assigned_to`, and permission names are rejected. Response fields are `id`, `listing_reference`, `contact_name`, `contact_email`, `contact_phone`, `message`, `status`, `consent_at`, `consent_version`, `created_at`, and `assignment`. `assignment` is `null` or `{user_id}`. The `id` is the enquiry reference returned at creation. The payload does not include an organization profile, the advertiser account, event metadata, or rows outside the caller's scope. Assignment does not add a reader. `property.publish` does not grant this read. There is no assignment or status-change method on these paths. An empty inbox is `200` with `count` 0.

Create body:

```json
{
  "property_id": "4c318845-5525-4966-ba65-efde611e7bbd",
  "mandate_id": "1bccf94b-6f7c-420d-b0c3-3052de4b1496",
  "listing_type": "sale",
  "title": "Kilimani apartment",
  "description": "A bright apartment with a private balcony.",
  "highlights": "Secure parking",
  "price": {
    "amount": 1250000000,
    "currency": "KES",
    "presentation": "asking",
    "negotiable": true,
    "billing_period": "sale"
  }
}
```

`amount` is an integer of minor units. A float or a boolean is rejected. Long-term rent and commercial leases use `month` or `year`. Short-term offers use `night` or `week`.

Mandate create body:

```json
{
  "property_id": "4c318845-5525-4966-ba65-efde611e7bbd",
  "listing_scope": "sale",
  "representative_user_id": "6f0c1a2b-3d4e-5f60-8172-93a4b5c6d7e8",
  "principal": "self",
  "evidence_reference": "Owner letter 2026"
}
```

The response includes `authority` and `authority_notice`. It does not include `legal_title_verified`.

{

## Ready response

`200` when every check is `ok`. `503` when any check is `error`. Dependency failures report `detail` as `unavailable` and log the exception on the server.

## Errors

DRF errors use this envelope:

```json
{
  "errors": {},
  "request_id": "trace-123"
}
```

## Conventions reserved for later resources

- Page-number pagination, 25 items, is configured.
- Anonymous traffic is throttled at 60 requests a minute. Authenticated traffic is throttled at 600. Health probes are exempt.
- The default permission is authenticated. A public business endpoint must opt out on the view and have a test that proves the opt-out is intentional.
- Serializers define the response. Clients should not depend on a Django model shape.
