# GLITTERS Cross-Engine Contracts & Interoperability Specification (`glitters_contracts` v1.0.0)

This package contains the authoritative typed execution envelopes, decision envelopes, cryptographic evidence verifiers, and typed data exchange bridges uniting all six GLITTERS algorithmic engines:

1. **Property Allocation & Optimization** (`glitters_allocation`)
2. **Property Valuation & Automated Appraisal** (`glitters_valuation_engine`)
3. **Geospatial Intelligence & Parcel Analytics** (`glitters_geospatial_engine`)
4. **Rental Pricing & Revenue Optimization** (`glitters_rental_optimization`)
5. **Construction Intelligence & Resource Optimization** (`glitters_construction_engine`)
6. **Financial Intelligence, Double-Entry Reconciliation & Anomaly Detection** (`glitters_financial_intelligence`)

## Core Principles

- **Zero DB Access**: Pure stateless computation envelopes.
- **Zero Caller Booleans**: Explicit cryptographic verification hashes and professional licenses.
- **Exact Minor Units**: All monetary values are integer minor units (KES cents).
- **Multi-Tenant Boundary Protection**: Strict tenant isolation on every envelope.
